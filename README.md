# Tarasquita: medios

Imágenes públicas de las publicaciones de Instagram de @salsatarasquita. La API de Instagram solo acepta fotos desde una URL pública, por eso viven aquí y se sirven con GitHub Pages.

- `feed/`: los carruseles, nombrados `campaña-cN-orden.jpg`.
- `historias/`: las fotos de las historias.

Solo imágenes. Los textos, el calendario y el publicador viven en el repositorio privado de la empresa.
